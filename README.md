## geoml

The **Geo**metry **M**odeling **L**ibrary is a stripped down version of the [TiGL library](https://github.com/DLR-SC/tigl), including only the geometry related functions and classes. It is intended to serve as the central geometry library for DLR to bundle development efforts.

It adds a new API on  top of the TiGL functions in the namespace `geoml`.
